
Genre Import Tool（ジャンル別インポートツール） README
バージョン: 1.0
対象: Unity 2020.3 以降（目安）
形式: 単一ファイル GenreImportTool.cs / GenreImportTool.unitypackage


--------------------------------------------------------------------------------
1. このツールについて
--------------------------------------------------------------------------------
Genre Import Tool は、Unity プロジェクトにインポートしたアセットを、
インポートする時点で自分で選んだ「ジャンル」ごとにフォルダ分けする
Unity Editor 拡張ツールです。

整理先のルートは既定で Assets/Sorted/ で、その下にジャンルごとの
フォルダを作ります。

  例:
    Assets/Sorted/アバター/
    Assets/Sorted/3Dモデル/
    Assets/Sorted/衣装/
    Assets/Sorted/ギミック/

対応する作業は次のとおりです。

  ・ツール画面からジャンルを選んで、ファイル／フォルダを取り込む
  ・ツール画面から .unitypackage を取り込み、展開後にジャンルへ移動する
  ・Project ウィンドウへ直接ドラッグ＆ドロップしたフォルダを検出し、
    後からジャンルを選んで移動する

--------------------------------------------------------------------------------
2. 作った理由
--------------------------------------------------------------------------------
Unity で作業をしていると、アバター、3Dモデル、衣装、ギミック、
シェーダー、アニメーション、テクスチャ・マテリアル、ツール／
スクリプトなど、種類の違うアセットがどんどん増えていきます。

そのまま Assets 直下に置き続けると、次のような問題が起きます。

  ・あのアセットがどこにあるか探す時間が増える
  ・似た名前のフォルダが増え、どれが何か分かりにくくなる
  ・後から整理しようとすると、移動の影響が心配で手が止まる

そこで「インポートした直後、その場でジャンルを決めて入れる」
仕組みにすれば、探す手間と整理の後回しを減らせます。

■ 自動判定を入れなかった理由
初期案には、拡張子やフォルダ名からジャンルを自動判定する案も
ありました。しかし自動判定は外れることがあります。
衣装なのか 3Dモデルなのか、ギミックなのかツールなのかは、
ファイル名だけでは決められない場合も多いからです。

そのため本ツールでは、要望どおり自動判定を採用していません。
「入れる人がジャンルを決める」方式にしたことで、誤判定による
誤分類が起きない設計になっています。

3. 仕様の詳細
--------------------------------------------------------------------------------
■ 基本情報
  ツール名        : Genre Import Tool（ジャンル別インポートツール）
  バージョン      : 1.0
  本体ファイル    : GenreImportTool.cs（単一ファイル）
  配布形式        : .cs ファイル単体 / .unitypackage
  名前空間        : YuukaTools.GenreImport
  メニュー        : Tools > ジャンル別インポート
  設定ファイル    : Assets/Editor/GenreImportSettings.asset
                    （初回起動時に自動生成されます。削除しないでください）
  整理ルート      : Assets/Sorted/（既定。画面で変更可能）

■ 既定ジャンル（8件）
  1. アバター
  2. 3Dモデル
  3. 衣装
  4. ギミック
  5. シェーダー
  6. アニメーション
  7. テクスチャ・マテリアル
  8. ツール・スクリプト

  ジャンルは追加・名前変更・削除ができます。
  削除してもフォルダと中身は削除されません（一覧からの削除のみ）。

■ 主な機能
  [ジャンル管理]
    ・ジャンルの追加（追加と同時にジャンルフォルダを作成）
    ・ジャンルの名前変更（フォルダ自体は自動リネームしません）
    ・ジャンルのフォルダ作成、Project ウィンドウで開く（Ping）
    ・ジャンルの削除（確認ダイアログあり）
    ・全ジャンルのフォルダを一括作成

  [インポート]
    ・ファイルを選んでインポート
      外部ファイルを 1 件選び、対象ジャンルのフォルダ直下へコピーします。
    ・フォルダを選んでインポート
      外部フォルダを丸ごと、対象ジャンルのフォルダ配下へコピーします。
      .meta ファイルはコピーしません。ドットで始まるフォルダは除きます。
    ・.unitypackage をインポート
      Unity 標準のインポートを実行します。詳細は「6. 制限」を参照。

  [保留（未分類）の処理]
    ・直接ドラッグなどで入った未分類のトップフォルダを自動検出し、
      「保留」リストに保持します。
    ・保留 1 件ごとに、ジャンル選択、移動、そのまま置く、
      後で決める、を選べます。
    ・「そのまま置く」を選んだフォルダは無視リストに入り、
      以後は検出されません。無視リストはリセットできます。

  [移動の安全策]
    ・移動は必ず AssetDatabase.MoveAsset で行います。
      OS 上でファイルを直接動かさないため、GUID と参照（.meta）が
      保たれます。
    ・移動前に「移動元 → 移動先」の確認ダイアログを必ず出します。
      キャンセルすれば何も動きません。
    ・移動先に同名がある場合は上書きせず、_1、_2 のように
      連番を付けた別名にします。

  [設定]
    ・整理ルートの変更
    ・「インポート時に確認画面を自動で開く」の ON／OFF

■ 検出対象と対象外
  検出対象:
    ・Assets 直下に新しくできたトップフォルダ
      例: Assets/NewCostume/
    ・Assets/Imported 直下に新しくできたトップフォルダ
      例: Assets/Imported/NewCostume/

  対象外:
    ・Assets 直下に直接置いた単体ファイル
      （フォルダ単位で整理する設計のため）
    ・整理ルート配下（Assets/Sorted/ など、既に整理済みのもの）
    ・Assets/Editor/ 配下、設定ファイル自身
    ・システム系フォルダ
      Assets/Editor, Assets/Plugins, Assets/Gizmos,
      Assets/Resources, Assets/StreamingAssets, Assets/WebGLTemplates

4. インストール方法
--------------------------------------------------------------------------------
■ 方法 A: .unitypackage から入れる（推奨）
  1. Unity で対象プロジェクトを開きます。
  2. GenreImportTool.unitypackage をダブルクリックするか、
     メニュー Assets > Import Package > Custom Package から
     GenreImportTool.unitypackage を選びます。
  3. インポート内容に Assets/Editor/GenreImportTool.cs が
     含まれていることを確認し、Import を押します。
  4. コンパイルが終わり、エラーが出なければ完了です。

■ 方法 B: .cs ファイルを直接入れる
  1. プロジェクトの Assets/Editor/ フォルダに
     GenreImportTool.cs を入れます。
     Editor フォルダがない場合は、Assets 直下に「Editor」
     フォルダを新規作成してください。
  2. Unity に戻るとコンパイルが走ります。
     エラーが出なければ完了です。

  ※ ファイル名と置き場所が上記以外だと正しく動きません。
  ※ 初回起動時に Assets/Editor/GenreImportSettings.asset が
     自動生成されます。このファイルは設定の保存先なので
     削除しないでください。削除するとジャンル設定、保留リスト、
     無視リストが初期化されます。

5. 詳しい使用方法
--------------------------------------------------------------------------------
■ 5-1. ツールを開く
  Unity メニューから Tools > ジャンル別インポート を選びます。
  メインウィンドウが開きます。ウィンドウは上から
  「設定」「ジャンル管理」「インポート」「保留」の順です。

■ 5-2. ジャンルを準備する
  初回は既定の 8 ジャンルが入っています。そのまま使えます。

  [新しいジャンルを追加する]
    1. 「新しいジャンル名」に名前を入力します。
    2. ［ジャンルを追加］を押します。
    3. ジャンルが一覧に追加され、同時に
       Assets/Sorted/<ジャンル名>/ フォルダが作成されます。
       同名のジャンルがある場合は追加できません。

  [ジャンル名を変更する]
    1. 一覧のテキスト欄で名前を書き換えます。
    2. ［名前を変更］を押します。
    ※ 安全のため、既存フォルダ自体は自動でリネームしません。
       フォルダ名も変えたい場合は Project ウィンドウで
       手動リネームしてください。Unity 経由のリネームなら
       GUID は保持されます。新しい名前のフォルダは別途作成されます。

  [その他の操作]
    ・［フォルダ作成］: そのジャンルのフォルダを作成します。
    ・［開く］: Project ウィンドウでフォルダを表示します。
    ・［削除］: ジャンルを一覧から削除します。
                フォルダと中身は削除されません。
    ・［全ジャンルのフォルダを作成］: 全ジャンル分を一括作成します。

■ 5-3. 方法 1 ― ツール画面からインポートする（推奨）
  1. 「インポート」欄で「対象ジャンル」をプルダウンから選びます。
     取り込み先パスが画面に表示されるので確認してください。
  2. 取り込み方法を選びます。

     a) ファイルの場合
        ［ファイルを選んでインポート］を押し、外部ファイルを
        1 件選びます。対象ジャンルのフォルダ直下へコピーされます。
        ※ 複数ファイルをまとめて入れたい場合は、先にフォルダに
           まとめてから b) を使うのが確実です。

     b) フォルダの場合
        ［フォルダを選んでインポート］を押し、外部フォルダを
        選びます。フォルダごと対象ジャンルの配下へコピーされます。

     c) .unitypackage の場合
        ［.unitypackage をインポート］を押し、ファイル選びます。
        注意ダイアログで［理解してインポートする］を押すと、
        Unity 標準のインポート確認画面が開きます。
        展開後、新しくできたフォルダは「保留」に検出されるので、
        手順 5-4 の方法で選んだジャンルへ移動してください。

■ 5-4. 方法 2 ― 直接ドラッグ＆ドロップした場合
  1. いつもどおり Project ウィンドウへフォルダをドラッグします。
  2. インポート直後、未分類の新しいトップフォルダが検出され、
     設定が ON なら「ジャンルの割り当て」確認画面が自動で開きます。
     ※ インポート処理中の不安定さを避けるため、画面は
        次のフレームで開く仕組みになっています。
  3. 確認画面で対象フォルダを確認し、ジャンルを選びます。
     その場で新しいジャンルを作る場合は「新しいジャンルを作る」に
     入力して［作成して使う］を押します。
  4. 次のいずれかを選びます。
     ・［このジャンルへ移動する］
         確認ダイアログで移動元と移動先を確認して移動します。
         保留が複数ある場合は、処理後に次の 1 件が順に表示されます。
     ・［そのまま置く（今後検出しない）］
         移動せず、無視リストに入れます。
     ・［後で決める］
         保留リストに残したまま画面を閉じます。
  5. 確認画面が開かなかった／閉じてしまった場合は、
     メインウィンドウ下部の「保留」からいつでも処理できます。

■ 5-5. 保留リストを処理する
  1. メインウィンドウの「保留 ― 未分類フォルダ」を開きます。
     保留がなければ「保留はありません」と表示されます。
  2. フォルダごとにジャンルをプルダウンで選びます。
  3. 次のいずれかを押します。
     ・［このジャンルへ移動］: 確認後にジャンルフォルダへ移動
     ・［そのまま置く］: 無視リストへ入れる（確認ダイアログあり）
     ・［後で決める］: 何もせず保留のまま残す
  4. 既に削除されたフォルダは、表示時に自動で掃除されます。
  5. 無視したフォルダを再び検出させたい場合は
     ［無視リストをリセット（再検出できるようにする）］を押します。

■ 5-6. 設定を変更する
  ・整理ルート: 既定は Assets/Sorted です。テキスト欄を変更すると
    保存されます。空欄にはできません。
  ・インポート時に確認画面を自動で開く: OFF にすると、直接
    ドラッグ時の自動表示だけが止まります。検出と保留への追加は
    続き、後からメインウィンドウで処理できます。

6. 制限・注意事項（必ずお読みください）
--------------------------------------------------------------------------------
■ .unitypackage の制限
  .unitypackage は Unity の仕様上、パッケージ内に記録された
  元のパスへ展開されます。任意のフォルダへ直接展開する公式 API は
  ありません。そのため本ツールでは、展開後に新しくできた
  トップフォルダを「保留」として検出し、続けてジャンルへ移動する
  流れにしています。「直接ジャンルフォルダへ展開される」動作では
  ありません。

■ パスを決め打ちしたアセットについて
  移動は AssetDatabase.MoveAsset で行うため GUID は保持されます。
  それでも、アセット内部のスクリプトなどがパスを文字列で
  決め打ちしている場合（例: "Assets/○○/..." とハードコード）、
  移動によって参照が壊れることがあります。
  心配なアセットは移動せず［そのまま置く］を選んでください。

■ その他の制限
  ・Assets 直下の単体ファイルは検出対象外です。
  ・ジャンル名にファイル名として使えない文字が含まれる場合、
    フォルダ名ではその文字が _ に置換されます。
  ・外部ファイル／フォルダのコピーで同名がある場合、フォルダは
    連番付きの別名になります。ファイルは上書きしません
    （コピーに失敗した場合はダイアログで知らせます）。
  ・対応バージョンは Unity 2020.3 以降が目安です。使用 API は
    それ以前からあるものが中心です。
  ・URP／HDRP、VRChat SDK 等とは競合しない想定です。

■ 検証についての正直な注意
  本ツールは配布時点で、ソースコードの構文と .unitypackage の
  形式（GUID、asset、asset.meta、pathname の格納と内容一致）は
  確認済みです。一方、作成環境には Unity がなかったため、
  Unity 実機でのコンパイルとインポート動作は未確認です。
  導入時にエラーが出た場合は、Console のエラー文面をそのまま
  控えておくと原因の特定が早くなります。

8. トラブルシューティング
--------------------------------------------------------------------------------
  Q. メニューに「ジャンル別インポート」が出ない
  A. GenreImportTool.cs が Assets/Editor/ にあるか、ファイル名が
     変わっていないか、コンパイルエラーが出ていないかを
     Console で確認してください。

  Q. ジャンル設定が初期化された
  A. Assets/Editor/GenreImportSettings.asset を削除すると
     初期化されます。必要ならプロジェクトのバックアップや
     バージョン管理から復元してください。

  Q. ドラッグしたのに確認画面が出ない
  A. 設定の「インポート時に確認画面を自動で開く」が OFF でないか、
     対象がフォルダかどうか、無視リストに入っていないか、
     システム系フォルダでないかを確認してください。
     保留リストには入っている場合があるので、メインウィンドウの
     「保留」も確認してください。

  Q. 移動に失敗した
  A. 失敗ダイアログに理由と移動元／移動先が表示されます。
     移動先の重複、対象フォルダの有無を確認してください。
     同名時は自動で連番が付く仕様です。
